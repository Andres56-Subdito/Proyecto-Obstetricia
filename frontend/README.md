# Frontend — Sentir Nacer

React + Vite + Tailwind. Ejecución (independiente del Backend Django):

```bash
npm install
npm run dev
```

Necesita `frontend/.env.local` con las claves de Firebase (plantilla: `.env.example`).
La configuración y la guía de personalización están en [GUIA_PERSONALIZACION.md](GUIA_PERSONALIZACION.md).

> Este Frontend **no está conectado** a la API de `../backend` (integración prevista en la Unidad IV).
